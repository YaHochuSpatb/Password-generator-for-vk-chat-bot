# Генератор паролей — чат-бот ВКонтакте

Чат-бот на Python, который в диалоге с пользователем генерирует надёжный пароль заданной длины и состава.

Проектно-исследовательская работа, секция «Информатика».
Автор: Сергеева Виталия Викторовна, ученица 10 «Б» класса, МАОУ СОШ № 33, Калининград.
Научный руководитель: Герасимова Тереза Дмитриевна.

## Что умеет бот

1. Пользователь пишет боту «начать»
2. Бот уточняет:
   - желаемую длину пароля
   - нужны ли цифры
   - нужны ли прописные буквы
   - нужны ли строчные буквы
   - нужны ли специальные символы
3. Бот генерирует пароль с помощью `random.sample()` из выбранного набора символов и отправляет его пользователю

## Технологии

- Python 3
- [vk_api](https://github.com/python273/vk_api) — работа с API ВКонтакте (Long Poll)
- модуль `random` из стандартной библиотеки

## Установка и запуск

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/ваш_логин/password-generator-bot.git
   cd password-generator-bot
   ```

2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

3. Создайте сообщество ВКонтакте, включите в нём сообщения сообщества и Long Poll API, получите токен доступа (Настройки сообщества → «Работа с API» → «Ключи доступа», с правом «Сообщения сообщества»).

4. Скопируйте `config_example.py` в `config.py` и вставьте свой токен:
   ```
   token = "ваш_токен_здесь"
   ```

5. Запустите бота:
   ```
   python bot.py
   ```

6. Напишите сообществу «начать» в личных сообщениях ВКонтакте.

## Пример диалога

```
Бот:       Привет! Я бот-генератор паролей. Хотите сгенерировать пароль? (да/нет)
Я:         да
Бот:       Какая длина пароля вас интересует? Введите число.
Я:         12
Бот:       Включать ли цифры (0123456789)?
Я:         да
Бот:       Включать ли прописные буквы (ABC...XYZ)?
Я:         да
Бот:       Включать ли строчные буквы (abc...xyz)?
Я:         да
Бот:       Включать ли специальные символы (!#$%&*+-=?@^_)?
Я:         да
Бот:       Ваш пароль: kR9$mZq2!wLp
```
